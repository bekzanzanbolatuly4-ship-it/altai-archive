# Archive Content Provenance

1. Distinguish verified archival records from synthetic demonstration data.
2. Preserve source, origin, dates, identifiers and available provenance.
3. Never invent historical facts, archive contacts, branch details or document metadata.
4. Distinguish original document language, description language and translation language.
5. Never imply that an original document has been translated without evidence.
6. Respect publication status, rights and access restrictions.
7. Preserve original files and metadata during imports.
8. Flag missing provenance rather than silently filling gaps.
9. Keep public descriptions concise, accurate and multilingual.
10. Verify every changed record before publication.
