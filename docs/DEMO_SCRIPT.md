# Сценарий демонстрации портала архива

Дата подготовки: 11 ноября 2026 года. Проверено на локальном коде `e5dfcd1` плюс незакоммиченные изменения этого рабочего сеанса. Production не обновлялся.

## Порядок показа

1. Открыть главную: https://altai-archive.vercel.app/ . Показать каталог и разделы как демонстрационный цифровой макет.
2. Открыть каталог: https://altai-archive.vercel.app/catalog . Ввести `карта горной местности` — это конкретная синтетическая демонстрационная запись, а не реальная архивная единица.
3. Открыть карточку демо-записи из результатов; обратить внимание на маркировку демонстрационного происхождения.
4. Открыть официальную справочную страницу: https://altai-archive.vercel.app/official-documents . Показать ссылки на русскую и казахскую публикации постановления № 289 в ИПС «Әділет». Сайт не принимает заявления, не оформляет заказы и не получает платежи.
5. При наличии рабочего локального кода показать `/assistant` и три запроса ниже. Сначала проверить, что ответ показывает режим и происхождение источника.
6. Завершить страницами `/about`, `/branches`, `/history`, `/exhibitions`; сведения с отметками демонстрационного или требующего подтверждения происхождения называть именно так.

## Проверенные запросы каталога

| Запрос | Ожидаемый результат | Основание |
|---|---|---|
| `карта горной местности` | «Карта горной местности (макет)» | Локальная запись `demo-02`, явно помеченная как макет; у неё нет архивного шифра. |
| `машинописного документа` | «Образец машинописного документа» | Локальная учебная карточка `demo-03`, не подлинный документ. |

## Проверенные запросы помощника

**Сценарий с источником:** `Найти фотографию`. В локальном коде без опубликованных записей он должен ответить в режиме `local-search`, привести карточку `demo-01` или `demo-04` и прямо сообщить, что это не AI-ответ и не подлинная архивная запись.

**Нет результатов:** `квантовая обсерватория на Марсе`. Ожидается `no-match` и пустой список источников, без предположений или выдуманной ссылки.

**Закрытый материал:** `PRIVATE CONTENT restricted personnel record`. Ожидается отсутствие содержимого и источников. Проверка также выполнена тестом с закрытой/draft записью с таким заголовком.

**Реальный генеративный AI запрос:** не подтверждён. Production не нашёл опубликованных публичных источников на контрольных запросах, поэтому маршрут не вызвал провайдера и не вернул `mode: ai`. Перед защитой не называть результат локального поиска генеративным AI.

## Резерв при отказе внешнего провайдера

В локальном коде соответствующий запрос к демонстрационным записям обслуживается локальным поиском с явной маркировкой `local-search`, выдержкой-источником и ссылкой на демонстрационную карточку. Этот режим не вызывает и не имитирует генеративный AI. Если нет совпадений, помощник отвечает `no-match`; если локальный набор также не подходит, при ошибке провайдера показывается ошибка с возможностью открыть каталог.

На Production этот новый резервный режим ещё не развернут. Для публичной защиты безопасный резерв — показать каталог напрямую и назвать материалы демонстрационными.

Следующие GET-запросы ответили HTTP 200 без редиректа 11 ноября 2026 года:

- https://altai-archive.vercel.app/
- https://altai-archive.vercel.app/catalog
- https://altai-archive.vercel.app/assistant
- https://altai-archive.vercel.app/official-documents

- https://altai-archive.vercel.app/branches
- https://altai-archive.vercel.app/history

Production browser rendered all eight pages without `pageerror` or console errors. On `/official-documents`, RU/KK/EN fit a 390px viewport, no development-only labels or local PDF links were found, and all ten unique external targets were checked: Adilet and gov.kz returned HTTP 200; eGov redirected to its identity page and returned HTTP 200.

Публичный `GET /api/documents` на проверенной версии ответил HTTP 500. `POST /api/assistant` вернул HTTP 200 с `mode: no-match`, пустыми цитатами и корректным языковым no-match на запросы `Find photographs`, `архивные документы`, `картографические материалы`. Значит ни подлинный генеративный ответ, ни источник из Production на проверке не получены. HTTP 200 здесь означает корректный no-match, а не успешный вызов модели.

## Ограничения

- Набор каталога синтетический; реальные архивные единицы в нём не представлены.
- В этой проверке нельзя определить версию сборки Vercel, её секретные env vars, активный provider/model или Redis-конфигурацию: публичный API не выдаёт эти сведения. Не делайте вывод, что AI_PROVIDER или старые OPENROUTER_* присутствуют либо отсутствуют.
- Дополнительная проверка лимита: первые пять последовательных запросов без совпадений получили HTTP 200, шестой — HTTP 429. Это совпадает с лимитом кода 5/IP/минуту; конкретный Redis backend публично не подтверждён.
- В локальном коде production AI fail-closed без корректных `APP_ORIGIN`, Upstash REST и Vercel IP; лимит — 5 запросов в минуту на IP и 20 суммарно. OpenRouter может ответить 429; автоматических повторов нет.
- Изменения ещё не deployed. Production API 500 и отсутствие доступных опубликованных метаданных требуют исправленной deployment и отдельной проверки после неё.
- Локальные файлы JSON и загрузки не являются постоянным хранилищем Vercel.
- Локальные оригиналы прейскуранта не опубликованы; ссылка ведёт на официальную публикацию в «Әділет».
