## Значение статусов

- **Реализовано** — функция есть в коде; реальность и актуальность данных проверяются отдельно.
- **Частично** — интерфейс и часть поведения готовы, но есть ограничение или непроверенная интеграция.
- **Демонстрационный режим** — используется синтетическое/иллюстративное содержание или временная модель без постоянного хранения.
- **Планируется** — полноценная реализация требует решения, источника, инфраструктуры или разрешения.

## Production caveats

Все восемь проверенных страниц сайта отдали HTTP 200 без редиректа и без браузерных ошибок. На проверенной опубликованной версии `GET /api/documents` отдал 500; запросы `/api/assistant` отдали no-match с HTTP 200 и пустыми источниками. Из шести последовательных unmatched запросов первые пять получили HTTP 200, шестой — 429, что соответствует лимиту 5/IP/минуту, но не подтверждает конкретный Redis backend. Публично определить deployment commit, provider/model или секретные env values не удалось. Локальные исправления read-only API и fallback поиска не попадают в Production без deploy.
